# Jefferies Navigation v2.0.0-beta.1

Jefferies Navigation introduces the approved Navigation Compass and its own
Home Assistant resource and configuration identifiers. The compass shows the
installed version and can show the rendered size with `size_debug: true`.
The expanded Hub compass returns to the collapsed room control on a tap and
reveals the version on a hold or Shift+Enter.

This beta carries forward the v1.10.0 feature set, including persistent Hubs
and Controls, Light palettes and presets, Sonos and Media, Climate, Charger,
Info Cube, responsive placement, Beam of Origin, classic popups and XY Pad.

Read the [migration guide](docs/V2_MIGRATION.md) before switching your dashboard
to the v2 resource.
